# 定义卡：抽什么、每一样怎么认

javmem 从包里抽四样东西：**事实、关系、变化、别名**，用到的人、公司、东西是**七类实体**。这几张卡说每一样算什么、不算什么。抽取的提示词、核对的规则、打分、`javmem gold check` 都照这一套；自己做金标准的时候照它标，标出来的才和 javmem 抽的比得上（整套怎么做见 [calibration.md](calibration.md)，文件怎么写见 [gold-format.md](gold-format.md)）。

卡上的例句、名字、数都是编的。“主人”是这份记忆的主人：对话包里说“我”的那个人。邮件包里没有主人，发信的、收信的照名字算。

## 0. 先看这五条

1. **只记原文里有的。** 原文写着的，或者从同一段话里能合理推出来的（推出来的标“推断”）。猜的不记。
2. **一条只说一件事**，写成一句单独拿出来也看得懂的话：“他”“那家”换成名字，“明天”“下周一”按说这句话的时间换成日子。数字、代码、名字照原文写，不翻译、不换算。
3. **每条都有出处**：哪一句（句子编号），那一句里能看出这件事就行。同一件事说了几次，记一条，出处列每一处。
4. **分清谁说的**：主人说的、Bot 说的、别人说的、转述的文件和邮件说的，不要混。
5. **拿不准的照样标**，打上“拿不准”、备注写一句为什么；影响大的打上“影响大”。审的时候先看这些。

## 1. 七类实体

| 类型 | 算 | 例子 |
| --- | --- | --- |
| 人 | 具体的一个人：有名字的；主人自己（名字写“主人”）；“我表姐”这种“我＋称呼”说的那一个（写“主人的表姐”） | 祝明远（“老祝”是他的简称） |
| 公司或机构 | 公司、银行、学校、医院、政府部门；部门、分公司、子公司也算，各自一个 | 南岭纸业、星桥银行、青禾设计 工程部 |
| 项目 | 要持续做一阵的一件事，或者长期的一类活 | 梧桐路展厅项目、每周对账 |
| 订单或合同 | 一张单子、一份合同一个：采购单、服务合同、保单 | NL-1107 采购单、展厅灯具合同 |
| 地点 | 有名字的地方：城市、园区、仓库、门店 | 北渡物流东郊仓库 |
| 资产 | 能持有的东西：股票、债券、基金、存款 | 晨光一号基金 |
| Bot | 在包里说话的 AI 助手（Bot 名单上的那几个） | demo-bot |

**起名字：**

- 用原文里这个东西最完整的叫法。同一个东西几种叫法，是一个实体，别的叫法记成别名（第 5 节）。
- 部门单独一个实体。原文没把部门和公司连着写、又看得出是哪家的，名字写成“公司名＋空格＋部门名”（“青禾设计 工程部”）：各家都有叫一样的部门，不带上是哪家的会被当成同一个。不要写成括号，“青禾设计（工程部）”会被当成青禾设计的另一个叫法。
- 东西和发行它、管它的那家分开：晨光一号基金是资产，发这只基金的公司另是一个公司或机构。
- 职位、干的活（“项目经理”“报关”）不是实体，写进事实。

**不建实体：** 泛泛的叫法（“孩子”“银行”“客户”“供应商”）、几样东西的合称（“那几张采购单”）、程序、某台机器。

## 2. 事实

以后会被问到的情况、数、决定、计划、偏好、规矩，都是事实。

### 事实的五类

| 类 | 说的是什么 | 例子 |
| --- | --- | --- |
| 事实 | 人、公司、项目、单子、东西的情况和数 | NL-1107 采购单订的是 45 吨牛皮纸。 |
| 主人的偏好和规矩 | 主人喜欢什么、要求怎么做、定下的规矩 | 主人要求北渡物流的送货单每张都拍照存档。 |
| 主人的决定和计划 | 主人定了的事、打算做的事 | 主人决定展厅开幕推到 11 月 28 日。 |
| Bot 的建议和判断 | Bot 给主人的建议、提醒、估算、判断 | demo-bot 建议灯具合同先付三成定金。 |
| 和主人有关的行情 | 主人持有的、在看的东西的价格和涨跌 | 晨光一号基金这周的净值是 1.032。 |

**怎么抽：**

- **明细一项一条。** 表格、清单、账单里每一行一条，不要只记合计；口径（哪天、哪一份、哪个账户）写进每一条。
- **数带全。** 一句话里和这件事有关的数都写上：单位、币种、日子、占比。
- **说了几版的，每一版一条。** 数变了、日子改了的不算同一件事，各记一条，写清是哪个时候的；新的那条写清从什么改成什么，再记一条变化（第 4 节）。同一样东西的同一项，前后几条用同一个属性名（都写“报价”、都写“开幕日期”），新旧才对得上。
- **转述的算原话。** Bot 转述的邮件、文件、账单里的内容，确定程度写原话，事实里写清出处（“据星桥银行的对账单……”）。

**确定程度：** 原话（说话人明说的，转述的外部内容也算）、推断（推出来的、估算的、Bot 自己的判断）、含糊（没定下来、打算、可能）。

**时间：** 事情发生或者生效的时间，不是说这句话的时间（当场发生的事除外）。精度照写到哪一级：分钟、日、月、季度、年，不知道的写不知道。

**不抽：** 寒暄、“好的”“收到”；Bot 正在做什么、要去查什么的过程话；只有问、没有答的；主人这一次让 Bot 做的事（“帮我查一下”，里面带着长期要求的只抽那一部分）；说话人说明是测试、示例、不算数的。

## 3. 关系

**关系和事实怎么分：** 会持续一段时间、以后会被问“现在是谁”“现在在哪家”“现在有什么”的，是关系；一次性的动作是事实。“田甜从 11 月 2 日起负责梧桐路展厅项目”是关系；“田甜 11 月 3 日去展厅看了现场”是事实。关系另记一条，事实照样抽。

**只记已经成立的：**

- Bot 的建议、提醒、对以后的猜测不算：“建议让田甜接手”不是负责，“可以考虑赎回”不让持有结束。
- 主人的打算、还没执行的吩咐不算：“打算换一家物流”；别人转述的打算也不算。
- 还在谈的、报过价的、只是在看的、下了单还没成交的，不算。
- 这些照样抽成事实。

**推出来的也记，标推断：** 签名、抬头里带着一家机构（任职于）；一家的账单、对账单里列着一样东西（托管于那家，账户的主人持有它）；在一家开过户、付过钱（客户是）。

### 两头允许的类型

方向照箭头：主体 → 客体。两头的类型不在这张表里的，核对那一步不收。

| 关系 | 主体 → 客体 |
| --- | --- |
| 持有 | 人 → 资产、人 → 订单或合同、人 → 公司或机构、公司或机构 → 资产、公司或机构 → 订单或合同、公司或机构 → 公司或机构 |
| 托管于 | 资产 → 公司或机构、订单或合同 → 公司或机构 |
| 负责 | 人 → 项目、人 → 订单或合同、人 → 人、人 → 公司或机构、Bot → 项目、Bot → 公司或机构 |
| 任职于 | 人 → 公司或机构 |
| 客户是 | 人 → 公司或机构、公司或机构 → 公司或机构 |
| 亲属 | 人 → 人 |
| 隶属于 | 公司或机构 → 公司或机构 |

### 关系的状态

| 状态 | 什么时候 |
| --- | --- |
| 生效 | 现在还成立 |
| 已结束 | 原文说了结束：卖光了、离职了、不管了、换成别人了 |
| 暂停 | 说了先停一停、先不管，没说结束 |

javmem 自己的账本里还有一种“被取代”，是它判新旧时自己记的，标金标准不用。

**开始、结束的日子只写原文说了的，说不出就空着：**

- 原文写了开始那天（入职、签约、到账那天），相对的说法（昨天、上周五）按说这句话的时间换成日子。
- 这句话本身就是开始的（“从今天起这件事归你”“刚签了”），写说这句话那天。
- 只说了现在还在的（“祝明远在青禾设计”“账上有这只基金”），开始那天空着：说这句话的时间只说明那时候它在。
- 窗口里别的日子（到期日、付款日、别的事的日子）不拿来当开始。
- 结束也一样：说了哪天结束写哪天；当场结束的写说这句话那天；只说结束了、没说哪天的空着。
- 换人、转走：旧的一条已结束，新的一条生效，换的那天（说得出的话）两条都写上。

### 持有

谁 → 他有的东西：人或公司 → 资产、一张单子或一份合同、一家公司的股份。

- **开始：** 买入成交、到账、签了；“我有”“账上有”；账单、对账单里列着。加买不另起一条。
- **结束：** 卖光、到期、赎回、转给别人；对账单上没有了。只卖了一部分的不算结束。从一家转到另一家不是结束，那是托管于变了。
- **不算：** 打算买、在观察、Bot 建议买卖、下了单还没成交的；借的、租的；房子、贷款、收藏品不记成持有（照样抽成事实）。
- **例：** 主人说“我上周在星桥银行买了两万份晨光一号基金”：主人 持有 晨光一号基金（生效），晨光一号基金 托管于 星桥银行。demo-bot 说“这只这周跌得多，可以考虑先赎回一半”：是建议，持有照旧，抽成一条 Bot 的建议和判断。

### 托管于

东西 → 放它的那一家：资产、单子 → 银行、券商这种替你保管的机构。同一样东西同一时间只在一家。

- **开始：** 在那家买的、转进那家、对账单列在那家名下。
- **转走：** 从 A 转到 B，按到账那天：A 那条已结束、B 那条生效。只是说了要转、正在转的，不改。卖光、到期的跟着结束。
- **不算：** 发行它的那家（谁发的，不等于放在哪家）；现金调来调去。
- **例：** “晨光一号的份额月底从星桥银行转到了海川证券，今天到账”（编的两家）：晨光一号基金 托管于 星桥银行（已结束，到今天），晨光一号基金 托管于 海川证券（生效，从今天起）。

### 负责

人或 Bot → 他管的事：人 → 项目、单子、客户（人或公司）、一家机构；Bot → 项目、一家机构。

- **开始：** 负责、管、归你、交给、接手、由某人跟、某人是对接人。
- **结束：** 不管了、交出去、改由别人做（旧的已结束、新的生效）、事情做完了；人离开了那家，代表那家的负责跟着结束。
- **暂停：** “先放一放”“暂时不跟”：写暂停，不算结束。
- **Bot：** 主人把一类活长期交给某个 Bot（“以后每周对账归你”）算；只交代了要长期做、没说归它的，标推断。
- **“A 或 B 负责”：** 两条都记，标推断。
- **不算：** 一次性的派活（回一封信、跑一趟、开这一次会）、“跟进一下”、休假时临时代一下、派了没接的、交给程序或某台机器的活。
- **例：** 主人说“展厅那摊从 11 月 2 日起交给田甜，老祝回去做门店”：祝明远 负责 梧桐路展厅项目（已结束，到 11-02），田甜 负责 梧桐路展厅项目（生效，从 11-02 起），另记一条变化（换人或换渠道）。

### 任职于

人 → 他在的那家公司或机构。可以同时几家，兼职、挂名也算。

- **说了部门的：** 客体写那个部门，部门归哪家另记一条隶属于，不再另连那家。只说了在哪家的，照旧连那家。
- **开始：** 签名里写着公司、“某家的某人”、入职、加入、接任。
- **结束：** 离职、辞职、退休。同一家换了职位：旧的已结束、新的另起一条；换了部门：新部门另起一条，原文说了从哪个部门调过来的，旧的那条已结束。
- **只从邮箱后缀看得出的**标推断；公共邮箱推不出在哪家。
- **不算：** 休假、只说是“同事”、抄送名单、还没定的人选。
- **例：** 信的签名写着“田甜｜项目经理｜青禾设计 工程部”：田甜 任职于 青禾设计 工程部，青禾设计 工程部 隶属于 青禾设计；“项目经理”写进事实。

### 客户是

客户 → 卖东西、给服务的那一家，读作“主体是客体的客户”：人或公司 → 公司或机构。供应商反过来写：“北渡物流是青禾设计的供应商”记成 青禾设计 客户是 北渡物流。

- **开始：** 开户、签了合同、付了第一笔钱、下了第一单；在那家买过东西的，推得出有账户，标推断。
- **结束：** 销户、不再合作、合同终止。很久没往来不算结束。
- **不算：** 还在谈、报过价、免费试用、定了还没签没付；和这份记忆无关的两家之间谁是谁的客户。
- 客户那边哪个部门来下单的，照旧连那家，不连部门。
- **例：** 主人说“南岭纸业第一批纸的钱我昨天付了”：主人 客户是 南岭纸业（生效，从昨天那天起）。

### 亲属

人 → 人，具体关系写主体是客体的什么人（表姐、哥哥、女儿……）。一头是主人的，主人当客体。

- 两头都要是具体的人：有名字的，或者“我表姐”这种。光说“妈妈”“孩子”的不起。
- **不算：** 朋友、同学、老乡，请来的阿姨、家教、助理。改了名字、写错了字是别名的事，不是又多了一个亲属。
- 只有离婚这类才结束。
- **例：** 主人说“我表姐欧阳青下周来展厅看看”：欧阳青 亲属 主人（表姐）；“下周来展厅”是事实。

### 隶属于

部门、分公司、子公司 → 它所属的那家，两头都是公司或机构，同一时间只归一家。人不连这一条：人在哪个部门记任职于（人 → 部门），部门再隶属于那家。

- **开始：** “某家的某部”；名字里写着是谁的分公司；某家旗下、某家的子公司；签名里部门和公司挨着写；写信人说“我们的某某部”（写信人那家）。
- 分公司下面的部门，两条都起：部门 → 分公司，分公司 → 那家公司。
- 名字里写着、签名里写在一起的，标原话；只能从“我们”、邮箱后缀推出是哪家的，标推断。
- **结束：** 划出去、撤销、合并掉、卖给了别家：旧的那条已结束；改归别家的，新的另起一条。部门改了名是别名的事。
- **不算：** 说股份的（谁占谁多少股，那是持有）；免责声明里顺带提到的关联公司；没有名字的部门（“各部门”）；产品归哪家。
- **例：** “青禾设计华南分公司 设计部”（编的）：青禾设计华南分公司 设计部 隶属于 青禾设计华南分公司，青禾设计华南分公司 隶属于 青禾设计。

## 4. 变化

变化是“以前是这样，后来变成那样”：同一样东西的同一项，前后两个说法不一样了。前后两条事实（或者关系）照记，另记一条变化，出处分清哪一句是变以前、哪一句是变以后。

### 变化的种类

| 种类 | 什么时候用 | 例子 |
| --- | --- | --- |
| 决定翻过来 | 定了的事又不做了，或者反过来了 | 主人原先说不去秋季展，后来决定去 |
| 计划改了 | 日子、做法、安排改了 | 展厅开幕从 20 号推到 28 号 |
| 价格变了 | 报价、价格、费率变了 | 南岭纸业的报价从每吨 4,200 元涨到 4,500 元 |
| 换人或换渠道 | 负责的人、对接的人、供应商、走的渠道换了 | 展厅项目从祝明远交给田甜 |
| 规则改了 | 主人的规矩、要求改了 | 主人原来要求每周五对账，改成每月最后一天 |
| 状态变了 | 单子、事情的状态变了 | NL-1107 采购单从“待发货”变成“已签收” |
| 数值变了 | 数量、金额、比例变了（价格的算“价格变了”） | NL-1107 采购单从 30 吨加到 45 吨 |
| 名字改了 | 一家公司、一个项目改了名字 | 梧桐路展厅项目改叫梧桐路体验馆 |
| 外面的事 | 外面的情况变了（市场、规定、别家的事），不是主人这边做了什么 | 星桥银行的跨行手续费从 5 元降到 0 |
| 定下来了 | 原来没定的，现在定了：从含糊到确定，不是改 | 展厅灯具原先在两家里挑，后来定了其中一家 |
| 说明白了（不算变化） | 后一句只是把前面说清楚、更正说法，事情本身没变；标出来是考别当成变了 | 前面说“月底交货”，后面补一句“就是 30 号那天” |

**还要写的：** 变的是哪一项（“报价”“负责人”“开幕日期”）、变以前和变以后的值；**说得不干脆的**（没直说改了，要看前后文才知道变了：“那就先按 4,500 吧”“以后有事找田甜”）另打一个标记；“说明白了”的标成不算变化。

**打分怎么认：** javmem 记下的前后变了（事实被新的替代、关系结束或者换了一头），后一头的出处落在“变以后”那几句上，算判出来了；写了“变以前”那几句的，前一头也要落上。“说明白了”的反过来考：javmem 在那几句上记了变化，算错。

## 5. 别名

别名是同一个实体的另一个叫法。一个叫法对一个实体：原文里的叫法，加上它指的那个标准名。出处是写着这个叫法的那一句。

### 别名的种类

| 种类 | 说明 | 例子 |
| --- | --- | --- |
| 别名 | 小名、昵称、外号、另一种语言的名字 | “甜甜”是田甜 |
| 笔误 | 写错了字 | “祝明运”是祝明远 |
| 改名 | 改过名字，旧名字也指它 | “梧桐路体验馆”是梧桐路展厅项目 |
| 简称 | 名字的一段、省掉一部分的叫法 | “南岭”是南岭纸业，“老祝”是祝明远 |
| 代码 | 编号、代码、字母缩写 | “CG001”是晨光一号基金 |
| 邮箱 | 邮件地址 | “tiantian@qinghe.example.com”是田甜 |
| 不是同一个 | 看着像、其实是另一个：不算别名，标出来是考别合错 | “南岭物流”不是南岭纸业 |
| 泛称（不建实体） | “银行”“那个客户”这种泛泛的叫法：不算别名，也不建实体，标出来是考别建 | 光说“银行”，不当星桥银行的叫法 |

**打分怎么认：** javmem 带着这个叫法的实体只有对的那一个，才算对；对的那个有、别的实体也有，算“另有实体也叫这个”；只落在别的实体上的，看是没合并（还是同一个东西）还是认错了。“不是同一个”的，叫法落到那个实体上算错；“泛称”的，为它建了实体算错。
